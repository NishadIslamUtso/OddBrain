## What this branch is

The session's renderer merged into current `main`, one app rather than two UI
trees. Main's engine spawn, permission cards, checkpoints, vault, capture
bridge, artifacts and Ollama handling are intact underneath. The session's
appearance system sits on top: 8 looks, 8 structural layouts, 9 palettes plus
the app default, 4 interface styles, 5 interface fonts, chat fonts and widths,
System/Calm/Balanced/Playful/Still with 0.5 to 1.5 speed and pause, all 77
scenes assignable to 8 roles, saved mixes, compare, the five-question quiz,
shortlist and notes, and JSON/MD/HTML/SVG/ZIP export.

Settings has 18 destinations and all the former profile actions. The sidebar
footer is one row (brain plus name) opening Settings, You.

## What was fixed or added in this pass

| Area | State |
|---|---|
| Attachments | Decode by kind, not extension. Pictures of any window-readable format become PNG at 1568 px. Text is read to 12,000 characters and says so when longer. PDFs require a text layer; a scan is refused by name. docx/xlsx/pptx list what was left out. Audio is refused with its measured duration and points at Dictate. Unknown files are refused, never guessed. No silent provider switch. |
| Read aloud | Uses the window's own voice, queues sentence-sized utterances so Chromium does not stop at fifteen seconds, strips markdown before speaking, keeps `snake_case` and decimals whole, and stops on unmount. The button is absent when the platform has no speech synthesis. |
| Dictation | Still `webkitSpeechRecognition`, with the existing in-line notice when the API is missing. No wake word, no continuous listening. |
| Plugins | The panel asks the installed engine what its own `plugin marketplace` help documents, shows the answer unchanged, and offers `claude plugin marketplace add` only after a confirm card with the exact line and locator. agy has no documented marketplace command, and the panel says that instead of inventing one. |
| Ollama download | The unpacker now has runtime limits (512 files, 1.5 GB per file, 4 GB unpacked) instead of pack limits, streams progress every 250 ms, and aborts on the cap. This is the fix for the 1.47 GB archive that died on a 692 MB DLL. |

## Not verified here

- No Electron binary in this sandbox, so no real desktop window was launched.
  Everything above is the renderer under Chromium plus Node tests.
- No signed-in `claude` or `agy` binary. The marketplace probe has never met a
  real CLI; it is designed to report what the installed build says, not to
  assume support.
- The Ollama archive was not downloaded here. The limits match the measured
  archive, but the unpack has not run against the real file on Windows.
- Windows installer, startup entry, quick window hotkey, and the extension are
  untouched by this pass and remain as they were on `main`.
