# Memory_OB Vault

Canonical memory for Hermes + Brain.
Default policy: check everything by default.
Time: Asia/Dhaka.

## Folders

- **00 System** — System documents (this README, schema)
- **01 Inbox** — Intake that still needs attention
- **02 Sources** — Capture record. Written once, never edited.
- **03 Memory** — Entities, events, connections — the seeded memory layer
- **04 Working Memory** — Current snapshot and open loops
- **05 Knowledge** — Reusable synthesis, always linked to sources
- **06 Review** — Questions, conflicts, keep-or-forget
- **07 Sharing Receipts** — What was sent where, and when
- **08 Journal** — Dated notes
- **09 Activity & Undo** — Audit log of every capture
- **10 People** — One file per person, decisions linked to sources
- **90 Archive** — Retired records, kept for reference

## Rules

- Everything starts as raw unconfirmed evidence.
- The confirmation card in the chat is the only place memory is confirmed.
- Deleted things go to recoverable Trash (90 Archive).
- No telemetry, no credentials, no phone-home.
