# START HERE

**What this vault is:** Long-term + working memory for every AI you use. App drives it, extension feeds it, vault organizes it.

**How to open:** Obsidian -> Open folder as vault -> select the Brain folder.

**Folder map:**
- 00 System/ - rules, schema, templates, connectors, privacy
- 01 Inbox/ - new imports, processing errors
- 02 Sources/ - originals, never rewrite: Conversations, Browser Activity, Web Pages, Laptop Files
- 03 Memory/ - Entities, Events, Connections (derived, source-linked)
- 04 Working Memory/ - Current Snapshot, Open Loops, Active (short-lived view of NOW)
- 05 Knowledge/ - reusable synthesis, linked to sources
- 06 Review/ - Questions, Conflicts, Keep-or-Forget, Cleanup, Monthly Audits
- 07 Sharing Receipts/ - exact context sent externally, with approval
- 08 Journal/ - daily notes Asia/Dhaka, event time vs capture time
- 09 Activity & Undo/ - what was captured/created/failed/sent
- 90 Archive/ - inactive derived notes, not source deletion

**Default capture:** Extension checks everything by default. If inaccessible -> logs "wasn't accessible" in 09 Activity & Undo + 01 Inbox/Processing Errors, no popup. See [[Privacy & Access]] for blacklist.

**Extension UX:** Capsule Hub style: capture as Capsule, library, drag-drop inject, version/branch, attachments. Quillbot style: inline suggestions in any text field, highlight for context.

**Video boundary:** OddBrain may keep source-linked video/audio/frame/OCR evidence and plans, but Kdenlive alone owns timeline, preview, undo, project, render, and export state. Video-link and Creative Library downloads always need visible approval; see [[Privacy & Access]].
