# Templates

Use these for capture. Keep YAML frontmatter. Link sources.

- Entity.md - person, project, topic, routine, goal
- Event.md - dated experience
- Memory Claim.md - small correctable claim
- Conversation Source.md - AI chat original
- Browser Visit - jsonl line format (see Browser Visit.json.md)
- Laptop File Reference.md - pointer to local file
- Daily Journal.md - 08 Journal/<year>/<date>.md
- Follow-up.md - open loop tracking
- Sharing Receipt.md - external send approval
- Source Scope.md - enabled scopes + blacklist
- Monthly Audit.md - dry-run report
- Capsule.md - reusable context bundle (Capsule Hub style)
