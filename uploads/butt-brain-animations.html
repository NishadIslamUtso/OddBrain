Minimal drop-in

Everything you need in your app: the rig markup, the keyframe sheet, and one call per status word.

<!-- 1. one host element per mascot -->
<div class="bbhost" id="mascot"></div>

// 2. build the rig once (mascot() is in this file) and mount it
host.innerHTML = mascot('s');
// 3. set the loop for the current status word
play(host.querySelector('svg'), loopForWord('Percolating')); // -> "cook"

How a loop is defined

Loops are data, not hand-written CSS. Edit this and you get a new loop everywhere (gallery, stage, exports).

boogie: {
  n:'Boogie', g:'Dance floor',
  pt:{ rig:'k-bob .62, k-sway 1.24', torso:'k-wiggle .31',
       armNear:'k-armJazz .62', armFar:'k-armJazzR .62',
       legNear:'k-tap .62', legFar:'k-tapB .62' },
  m:'grin', e:'hidden', fx:'notes', bl:1
}

Part keys: rig torso armNear armFar legNear legFar glasses pupilL pupilR. Fields: m mouth, e eyes, gl glasses up, fx overlay, pr prop, bl blush, f CSS filter, once for one-shots.

Word → loop map

187 words out, distinct loops. Unknown words fall through to a keyword guesser (guess()): dance|boogie|shimmy → boogie, bake|cook|brew|simmer → steam, think|ponder|muse → think, and so on.
