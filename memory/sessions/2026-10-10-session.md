## 2. The Tic Tac Toe loop — fixed structurally, not by patching

Two changes, both permanent:
1. The system prompt is a plain instruction with **no code example**. The old one seeded a
   Flappy Bird example and qwen2.5:3b produced a game on every reply.
2. Artifacts are created **only** when the user explicitly asks
   (`lib/artifacts.explicitlyAsked`) or flips artifact mode in the composer. Any code block
   can still be promoted by hand with "Open in artifacts".
Plus: Settings → System → **Reset local data** clears any already-looped chat.

## 3. Ollama CORS removed as a problem

`vite.config.js` proxies `/ollama` → 127.0.0.1:11434 and `/vault` → 127.0.0.1:8765, with a
`/__ai_proxy_ping` marker. The browser stays same-origin, so Ollama's origin check never
runs and `OLLAMA_ORIGINS` is no longer needed. The app detects the proxy at startup and
falls back to direct URLs for static builds.

## 4. Vault API

`server/vault-api.cjs` rewritten: it finds the repo vault at `../../../vault/AI-Brain` and
adds `GET /status`, `/capsules`, `/today`, `GET`+`POST /blacklist`, plus `artifact` and
`journal` capture types. Blacklist changes are written to `00 System/Privacy & Access.md`
and `00 System/Connectors/Source Scope.md` and logged to `09 Activity & Undo`.
